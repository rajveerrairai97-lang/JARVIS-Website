# JARVIS — Personal Productivity Assistant

A Windows desktop productivity assistant designed to help users manage tasks, deadlines, and routines with voice announcements and a futuristic dashboard.

🌐 **Live Website:** https://jarvis-website-psi.vercel.app/

## Features

- Task and deadline reminders
- Voice announcements
- Futuristic dashboard
- Local-first design

## Download

Get JARVIS for Windows from the [official website](https://jarvis-website-psi.vercel.app/).

## Installation

1. Visit the website above.
2. Download the Windows installer.
3. Run the installer and follow the setup instructions.
